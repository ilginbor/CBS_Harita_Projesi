\# CBS Harita Projesi



Bu proje React, ASP.NET Core Web API, PostgreSQL ve PostGIS kullanılarak geliştirilmiş bir harita çizim ve sorgulama sistemidir.



\## Özellikler



\- Kullanıcı kayıt ve giriş sistemi

\- JWT tabanlı kimlik doğrulama

\- Admin ve normal kullanıcı rol sistemi

\- OpenLayers harita ekranı

\- Point, LineString ve Polygon çizimi

\- Çizim bitince popup ile isim, renk ve açıklama girme

\- Veritabanına WKT ve geometri bilgisi kaydetme

\- Polygon altında kalan obje sayısını hesaplama

\- Sorgulama ekranında grid listeleme

\- Haritada Gör butonu ile objeye zoom yapma

\- Soft delete ile çizim silme



\## Teknolojiler



\- React + Vite

\- PrimeReact

\- OpenLayers

\- ASP.NET Core Web API

\- Entity Framework Core

\- PostgreSQL

\- PostGIS

\- NetTopologySuite

\- JWT Authentication
